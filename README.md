# 🌿 Garden Party - 初心者向け安全セキュリティテンプレート

このプロジェクトは、初心者がWebサイトを制作し、インターネット（GitHub等）に公開する際に、**「APIキーを安全に隠し、漏洩を確実に防ぐ」**ための学習用・実証用Webテンプレートです。

特別なビルドツール（Node.jsなど）は一切不要で、ファイルをダブルクリックするだけで動作し、そのままネットに公開できます。

---

## 📁 フォルダ構成

```text
gardenparty2/
├── index.html          # メインの画面（HTML）
├── style.css           # 画面の見た目・デザイン（CSS）
├── app.js              # 動きやセキュリティの検証処理（JavaScript）
├── config.example.js   # 設定ファイルのテンプレート（Gitで公開しても安全）
├── .gitignore          # 公開してはいけないファイルを指定するGitの設定
└── README.md           # この説明書
```

---

## 🚀 ローカル環境（自分のPC）での使い方

このテンプレートには、APIキーを安全に扱う仕組みがあらかじめ組み込まれています。以下の手順でセットアップしてください。

### ステップ 1: 設定ファイル（`config.js`）の作成
1. `config.example.js` ファイルをコピーし、同じフォルダに貼り付けます。
2. 貼り付けたファイルの名前を **`config.js`** に変更します。

### ステップ 2: APIキーの設定
1. `config.js` をメモ帳やVS Codeなどのテキストエディタで開きます。
2. 中身の `YOUR_API_KEY_HERE` を、あなたが取得した実際のAPIキー（Google Mapsや植物データベースAPI等）に書き換えて保存します。

```javascript
const CONFIG = {
  // ここに本物のAPIキーを入力します
  GARDEN_API_KEY: "AIzaSyYourRealApiKeyHere...",
  APP_NAME: "Garden Party",
  VERSION: "1.0.0"
};
```

### ステップ 3: ブラウザで確認
1. `index.html` をダブルクリックしてブラウザで開きます。
2. 画面上の「セキュリティステータス・検証ボード」が **「安全: 接続準備完了」**（緑色）になっていれば成功です！

## 🔒 なぜこの構成だと「安全にネットに公開」できるのか？

### ① `.gitignore` が機密ファイルを自動ブロック
プロジェクト内にある `.gitignore` ファイルには、以下のように書かれています。
```text
config.js
```
これにより、プロジェクトを Git や GitHub にアップロード（プッシュ）する際、**本物のAPIキーが書かれた `config.js` だけが自動的に無視され、ネット上には絶対に公開されません。**

### ② `config.example.js` による共同開発のサポート
代わりに、ダミーの文字が入った `config.example.js` はGitHubにアップロードされます。他の開発者があなたのコードをダウンロードしたときは、そのテンプレートをコピーして各自のAPIキーを入れるだけで、すぐに開発に参加できます。

## 🌐 インターネットへ公開（デプロイ）する手順と注意点

Netlify、GitHub Pages、Vercelなどの無料サービスを使えば、このプロジェクトを数分で世界中に公開できます。

### ⚠️ 最重要：外部APIの「ドメイン制限」を設定する
ネット上に公開する場合、ブラウザ（フロントエンド）からAPIを呼び出す仕組み上、公開したサイトのソースコードや通信をのぞき見ると、APIキーが確認できてしまいます。

これを悪用されないために、**APIの提供元（Google CloudやFirebaseなど）の設定画面で必ず「ドメイン制限」を設定してください。**

1. APIキーの設定ページ（例: Google Cloud Console）にアクセスします。
2. APIキーの編集画面を開き、「キーの制限」で **「HTTPリファラー（Webサイト）」** を選択します。
3. 制限リストに、あなたが公開したサイトのURLを追加します。
   * 例: `https://your-username.github.io/*`
   * 例: `https://your-site-name.netlify.app/*`
4. 保存します。

> [!IMPORTANT]
> **ドメイン制限を設定することで得られる効果：**
> たとえ悪意あるユーザーがあなたの公開サイトからAPIキーをコピーしたとしても、そのユーザーのPCや別のサイトからは一切そのキーが使えなくなります。結果として、不正な請求や悪用からあなたの身を守ることができます。

## 🛡️ フロントエンドの基本的なセキュリティ対策

このテンプレートの `app.js` では、以下の対策も体験できるようになっています。

### XSS（クロスサイトスクリプティング）対策
ユーザーが入力したコメントや文字を画面に表示する際、JavaScriptで `innerHTML` を使って表示させると、入力された悪意あるHTMLタグやJavaScriptがそのまま実行されてしまう脆弱性（XSS）が生じます。

* **対策**: `app.js` 内では、出力を `textContent` を使用して行っています。これにより、タグが自動的に安全な文字としてエスケープ処理され、ブラウザ上での不正なプログラム実行を未然に防いでいます。
